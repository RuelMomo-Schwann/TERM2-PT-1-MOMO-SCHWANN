Game Design & Scratch

Path Unlocked - Obstacle Game

"Path Unlocked" is an interactive geometry-based precision obstacle game inspired by mechanics from Geometry Dash. Developed in Scratch, the game challenges players to navigate a square character through moving spikes, precise platform jumps, and increasing speed levels. Building this project provided a strong understanding of event listeners, variables, collision detection logic, and custom animation loops.

  • Precision jumping mechanics and obstacle collision logic
  • Progressive level difficulty and high score tracking
  • Custom visual effects and sound timing

Web Development

Responsive Student Portfolio Website

This portfolio website is a personal web development project designed using pure HTML and modern CSS. Built without complex JavaScript frameworks, it features advanced CSS techniques including CSS Flexbox layouts, frosted glassmorphism cards (`backdrop-filter`), CSS variables for smooth Light/Dark theme switching, keyframe entrance animations, and responsive styling.

  • Multi-page navigation structure with smooth hover pill effects

Scientific Research

Modified Tidal Turbine Research (SIP)

This Science Investigatory Project (SIP) explores the development and testing of a modified tidal turbine designed to capture renewable kinetic energy from ocean currents off Philippine coasts. The research focuses on optimizing blade angle curvature and rotor hydrodynamics to generate stable clean electricity even in low-velocity coastal tides, presenting a sustainable eco-friendly solution for off-grid coastal communities.

  • Hydrodynamic blade curvature testing for maximum efficiency
  • Renewable energy application for coastal Philippine water channels
  • Scientific method data collection, trials, and hydrodynamic simulation
